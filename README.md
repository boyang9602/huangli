# 黄历 Chinese Almanac

一款提供传统中国日历和每日历法信息的 Chrome 扩展程序。

A Chrome extension for the traditional Chinese calendar with daily almanac information.

## 特性 Features

- 公历和农历视图 / Gregorian and Chinese calendar views
- 节气、节日、每日历法（宜忌、吉神、凶神等）/ Solar terms, festivals, daily almanac (auspicious and inauspicious activities, gods, etc.)
- 干支式年/月/日显示 / Stem-branch year/month/day display
- 跳转到任意年份/月份 / Jump to any year/month
- 在 Google 日历或 Outlook 日历中打开任意日期 / Open any date in Google Calendar or Outlook Calendar

## 注意 Note
中国历法是[阴阳混合历](https://zh.wikipedia.org/wiki/%E9%98%B4%E9%98%B3%E5%8E%86)，即月份追踪月球周期，而季节和年份追踪太阳周期，而非[阴历](https://zh.wikipedia.org/wiki/%E9%98%B4%E5%8E%86)。  
The Chinese calendar is a [lunisolar calendar](https://en.wikipedia.org/wiki/Lunisolar_calendar), meaning that months follow the lunar cycle while seasons and years follow the solar cycle, rather than a [lunar calendar](https://en.wikipedia.org/wiki/Lunar_calendar).
